# 三位课堂客户 · WorkBuddy 实操指令

这是林黛玉、孙悟空和唐僧的虚构练习。请在当前 WorkBuddy 新任务里执行，所有文件存进该任务工作空间下的「课堂示例知识库」。仅使用下列课堂材料，不读取真实微信或现有客户库，不对外发送消息。

## 练习资料

- 三份微信原文：https://raw.githubusercontent.com/zhqiang1989/my_AI_workflow/master/materials/customer-chats.md
- 产品来源和课堂摘录：https://raw.githubusercontent.com/zhqiang1989/my_AI_workflow/master/materials/product-sources.md

链接读不到时，告诉我具体哪一个失败。我可以下载文件后拖进当前对话。产品原件一时读不到时，把相关字段写成「未核实」，仍可继续做客户画像和需要补问的问题。

## 按顺序完成

1. **准备知识库。** 用已安装的 `llm-wiki` 或 `llm-wiki-kit`。都没有时用文件工具继续。记录这次用的技能和知识库路径。
2. **归档对话和产品资料。** 按文件中的三个文件名分别保存微信原文，每份核对 10 条。保留原文、日期、说话人和消息编号。三人的正式风险测评都未提供。产品核对用资料里的第 174 期，标清公告和说明书出处。课堂摘录只供练习，若用于现实业务，需另查官方最新条款、渠道和额度。
3. **生成三份画像。** 每位写清「这笔钱」「怎么聊」「还要问」。引用可在原文查回的一条消息，保留「暂估」「大概」之类的限定。用已安装的 UI UX Pro Max 整理 HTML。有我上传的人物图就用，缺图或技能时直接交可离线打开的文字卡片。另存 Markdown 画像汇总。
4. **写孙悟空的微信草稿。** 项目尾款和个人资金分开。缺正式风险测评或产品条件未核实，就不列已匹配推荐。草稿模仿经理小陈的口气，先回应实际关切，再问一个关键问题，最多三条短句。内部核对与给客户的草稿分开。
5. **报告交付。** 报出三份原文、画像 HTML、画像汇总和消息草稿的路径。另列具体缺项和测试中没用上的技能。

更多步骤和人物配图见[在线实操手册](https://zhqiang1989.github.io/my_AI_workflow/)。
