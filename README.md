## 课件结构

页面顶部两个页签：

- **操作手册**：准备 / 建库 / 保存材料 / 编译画像 / 比条件写草稿 / 定时试跑 / 使用边界。
- **客户对话样例**：支持单人或全量复制，带保存指令；与第3步共用同一份内嵌原文，第4步统一编译。

先确认WorkBuddy已登录且能回复。建库后填写实际完整路径，在共享名单处选择客户或匿名编号；后续提示词同步更新。新开任务需重新选工作空间。

Skill、专家角色和工具使用不同标记，鼠标悬停、键盘聚焦或手机轻点可看简短解释；复制只取提示词正文，不带教学注释。第5步提供可替换的“我的表达样例”，用于仿照经理口气写审阅草稿。

遇到安装、登录或权限确认，按实际界面处理；不能用“已复制”证明任务已执行。定时任务先暂停、试跑并核对记录，再由本人决定是否启用。

## 数据与合规说明

- 客户姓名、资产、企业信息全部为教学虚构并已脱敏，不涉及真实客户数据。
- 真实客户资料仅在行内批准的环境和范围内处理；本地文件路径不代表模型处理全程留在本机。
- 产品信息来自建行公开渠道，以官方最新公告为准。
- 课件保留人工审核要求：AI 生成话术须经客户经理审核后使用。

本仓库提供课堂材料和提示词，不自动安装Skill、读取微信、执行模型任务或创建定时计划。页面交互与复制检查不等于WorkBuddy实际业务流程已通过验证。
