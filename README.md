# 私行客户经理 · WorkBuddy + LLM Wiki 基础实操手册

面向零基础学员的 WorkBuddy 实操课件。先用虚构样例练习建库、整理资料、编译画像和准备沟通草稿。

## 文件说明

| 文件 | 用途 |
|---|---|
| `私行客户经理_WorkBuddy实操手册.html` | 主课件。示例工作流、完整工作流、客户对话样例三个页签 |
| `samples/客户微信_*.txt` | 三段虚构脱敏的客户微信对话（含行内客户档案卡），用于课堂演示 |
| `samples/微信对话样例.zip` | 上面三个 txt 的打包，方便发到微信文件传输助手 |

## 课件结构

页面默认打开**示例工作流**，用「课堂示例知识库」练习。**完整工作流**用独立的「私行工作知识库」整理一位客户的微信记录和公开产品资料。WorkBuddy 会询问日常沟通还要参考哪些资料，按确认范围补充后起草消息。试跑通过后，可用本地定时任务归档该客户新增的微信，并更新已确认的产品资料。**客户对话样例**提供三段对话，可单段复制或连同录入指令一起复制。

提示词可以直接复制到 WorkBuddy。微信备注名、来源范围和定时时间在 WorkBuddy 对话里确认。

## 数据与合规说明

- 客户姓名、资产、企业信息全部为教学虚构并已脱敏，不涉及真实客户数据。
- 产品信息来自建行公开渠道，以官方最新公告为准。
- 课件保留人工审核要求：AI 生成话术须经客户经理审核后使用。
