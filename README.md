# 私行客户经理 · WorkBuddy + LLM Wiki 基础实操手册

面向零基础学员的 WorkBuddy 实操课件。先用虚构样例练习建库、整理资料、编译画像和准备沟通草稿。

## 文件说明

| 文件 | 用途 |
|---|---|
| `私行客户经理_WorkBuddy实操手册.html` | 主课件。示例工作流、微信连接与定时、客户对话样例三个页签 |
| `samples/客户微信_*.txt` | 三段虚构脱敏的客户微信对话（含行内客户档案卡），用于课堂演示 |
| `samples/微信对话样例.zip` | 上面三个 txt 的打包，方便发到微信文件传输助手 |

## 课件结构

页面默认打开**示例工作流**，按顺序练习前五步。**微信连接与定时**收录电脑微信归档和定时任务。**客户对话样例**提供三段完整对话，可单段复制或连同录入 LLM Wiki 的指令一起复制。

所有 prompt 自包含，复制发送即可，学员无需手动建文件夹、切换专家或点击定时任务界面。

## 数据与合规说明

- 客户姓名、资产、企业信息全部为教学虚构并已脱敏，不涉及真实客户数据。
- 产品信息来自建行公开渠道，以官方最新公告为准。
- 课件保留人工审核要求：AI 生成话术须经客户经理审核后使用。
